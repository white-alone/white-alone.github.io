大疆4G模组和闲鱼伪基站二三事

2026-07-29IoT

0x10 大疆4G模组 ​

最近大疆一代4G模组很火，体积小，频段支持很全，一堆公众号在吹，上闲鱼一看，果然价格暴涨，原本三四十的，现在一堆卖七八十甚至还有卖上百的。

其实本质上就一个移远的USB EG25模块，只不过因为体积小巧，做工精致，加上因为要跟随大疆无人机发往全球，所以在频段兼容上做的比较好，用来当USB 4G网卡，插入wifi路由当4G路由都不错。

github上有个VoHive项目，也就是个开源蜂窝网络/蜂窝模组管理与网关系统，简单的说，就是猫池，作者最近也闭源项目只留了二进制，原因未知。闭源后的版本不建议大家使用，毕竟有点擦边，安全第一！

我在闲鱼蹲了几天收到了6个模块，修改下PVID，将DJI的私有ID改成EG25的通用ID，就可以当普通4G模块一样用，用AT指令可以读到版本号。这时候，就遇到了问题。

众所周知，软件都有版本号，硬件设备里跑了软件，所以也就有所谓的固件版本号，我用AT指令读就发现，买到的6个模块有3个版本：

  • QDC507GLEFM21_01.001.02.001
  • QDC507GLEFM21_01.001.02.004_BETA0611_01.001.02.004
  • QDC507GLEFM21_01.001.02.004

然后我就联系了大疆客服，提交了我买的模块的SN、ICCID、IMEI、和固件版本号，问01.001.02.004是不是官方最新版本，客服说要工程师核实，后续电话邮件回复。 然后第二天，收到了官方客服电话说，没有版本号，没错，没有版本号！看了下邮件，也是这么说。

当时我就无语了，在大疆APP里是能看到4G模块的固件版本的，在遥控器上也能看到固件版本并能升级。官方支持就这么糊弄用户么，我就给客服说官方技术支持要给客户正确信息，不要给错误信息误导用户，怎么可能没版本号，苹果ios都有版本，说着说着客服直接撩电话了。。。态度简直了。。。 再后面我在微博吐槽了一下，立马就有人联系我，扯半天又说踢客服表达歉意，又是要赠与小礼品，我直接没要，最后图穷匕见：能删了帖子么？我直接说不需要小礼品，我也没黑大疆，只是如实表述了事情和感受而已。

DJI大疆以前是我很佩服的一家企业，毕竟能在无人机这个领域杀出一片天，在360时候就对无人机很感兴趣，也搞过GPS模组的中间人劫持绕过禁飞区限制，也是当年清华无人机表白事件的亲历者，我也买过大疆不少产品，但现在真的感觉不行了，负责安全的哥们被恶心走了，这次这个固件事件更是拉低了我对DJI的印象。

通过官方APP和遥控器，确认了最新的固件是V01.01.0204后，老版本就得升级上去了，因为我手头没有用1代4G模块的无人机，那就回到老本行了，dump固件再烧录就行了，有高通芯片9008模式也不怕变砖，最后用AI辅助搓了个工具。

0x11 固件备份和升级 ​

QDC507 使用 128 MiB NAND，几何参数固定为 2 KiB/页、64 页/块、1024 块。普通模式通过 AT 串口读取身份和 USB 配置；进入 Qualcomm EDL 后，工具加载经过验证的 Firehose programmer，直接读取或写入 NAND。

备份原理 ​

备份操作不会写入固件分区。流程如下：

  1. 读取型号、固件、SN、IMEI、ICCID、SIM 状态和原始 USB 配置。
  2. 将 SN、IMEI、ICCID 和固件 manifest 写入 state.json，防止中途换错模组。
  3. 必要时临时切换到 2C7C:0125，然后进入 05C6:9008 EDL。
  4. 使用相同 loader 连续读取两次完整 128 MiB NAND。
  5. 检查两个文件大小均为 134217728 字节，并比较 SHA-256。
  6. 校验 NAND 几何和兼容性区域，随后复位模组。
  7. 再次验证 SN、IMEI、ICCID、固件和 USB 配置，并恢复原 USB ID。

只有两次读取完全一致且最终身份验证通过，状态才会进入 complete。双份镜像是一致性证据，不能只凭单次读取判断备份可靠。

升级原理 ​

升级会先执行与独立备份相同的双份整片 NAND 备份。备份通过后，仅允许写入：

分区用途大小
RAWDATA固件原始数据512 KiB
aboot应用启动加载器1.25 MiB
boot内核和启动文件系统5.375 MiB
recoveryfs恢复文件系统5.25 MiB
system主系统镜像68.125 MiB
运行时会重新生成只包含上述五个分区的 rawprogram XML。EFS2、sys_rev、usr_data、IMEI/SN 和射频校准区不会出现在写入清单中。

写入完成后还有两层验证：

  1. 逐分区回读，大小和 SHA-256 必须与内置 manifest 一致。
  2. 再读取一次完整 NAND。五个目标分区必须等于正式固件，所有非目标区域必须与升级前备份逐段一致。

因此升级验证的是“目标分区正确变化，其他字节没有变化”，而不只是检查工具返回成功。恢复操作采用相同写入和审计流程，但分区镜像从同一 SN 的历史备份生成，并通过 bound_serial 禁止跨模组恢复。

Docker 部署 ​

要求原生 Linux amd64、Docker、稳定 USB 供电，并且同时只连接一个 QDC507。镜像需要宿主 PID、/dev、/sys 和特权模式来处理 USB、驱动及ModemManager。创建持久化目录后运行：

bash
mkdir -p qdc507-manager/{data,backups}
cd qdc507-manager

docker run -d \
  --name dji-qdc507-firmware-manager \
  --restart unless-stopped \
  --privileged \
  --pid host \
  --platform linux/amd64 \
  -p 127.0.0.1:8080:8080 \
  -v "$PWD/data:/data" \
  -v "$PWD/backups:/backups" \
  -v /dev:/dev \
  -v /sys:/sys \
  canghaiwuhen/dji-qdc507-firmware-manager:0.1.0

浏览器打开 http://127.0.0.1:8080/。网页无登录验证，端口必须保持绑定127.0.0.1，不要暴露到公网或不可信局域网。

备份-升级完固件之后，修改USB ID，就可以直接使用了。

在Ubuntu 24.04上直接可以看到移动网络，其他玩法网上文章很多，有兴趣自行搜索。 最后再补充一下，这个模块没有板载天线，如果不接天线信号回很差，模块用的是2mm CRC9接口，大疆官方称为TS5接口，要么高价买大疆4g模块天线，要么直接买CRC9的天线或者转接线。注意，弯头的只能插1个到main接口，因为2个接口太近了。

0x20 闲鱼上的伪基站 ​

伪基站的打击是多个部门发文的，因为这个原因，淘宝至今还屏蔽了USRP关键字，但也只有淘宝，京东、PDD全都没有屏蔽，但神奇的是，淘系的闲鱼，没有屏蔽！之前TQTT李总的淘宝店售卖B210卖的好好的，突然某天被处罚了，原因未知，不知道是竞对举报，还是内部小二的原因，我还内网发帖找相关人员掰扯过，可惜没结果。 闲鱼就更神奇了，USRP没有屏蔽，但应我提的建议屏蔽了SSRP，但众所周知，闲鱼的黑话、暗号太多了，规避屏蔽的方法很多，最简单的办法就是找一个ssrp主板的照片，用图搜， 就能搜到一众诈骗犯的上游。

比如下面几个，全是伪基站，还有搞C118短信嗅探，有一个算一个都不干好事的。而且很多还会互相留言引流，找到一个，就能找到一堆。

针对特定关键字、图片识别其实我都给闲鱼安全的同学反馈过，之前我看到了转给他，他还会处理，到后面直接已读不回了。其实也能理解，这种处置，费时费力不讨好，这些诈骗犯卖设备，不干好事的人买了，坑的人又找不到他们头上，甚至都找不到淘系，那干这事对KPI有啥价值？

伪基站广告/钓鱼短信、C118短信嗅探已经是十多年前的技术了，国内2G基站基本关完了，3G马上也要退完了，运营商和无委会早就有成熟的检测识别技术，基本上只要打开了，过不了多久就可以领手镯了，过往也有非常多的判例，但总有人不信邪，或者拿去东南亚，总之，不干好事。

然而遗憾的是，在闲鱼上你就算看到了，举报，99.99%都不会成立的，这就是闲鱼，你看到了有问题的，却无可奈何。还有那些低价引流的，挂低价进去问就是高价的，举报也每一个成立的，白白浪费了用户的时间但提高了app的使用时间，这就是厂商的劣根性。

从不收手续费到超限额收到每笔都收，钱挣到了，有能力开发新功能了，web版也回来了，但它所承担的社会责任依旧拉胯，他们有赔付的资金池，遇到纠纷当用户闹得大，就贴钱补偿，用户不闹不处理。可惜的是一家独大，转转比闲鱼还差很多，当你的58同城之类的早就没落了，ebay进不来，众人苦闲鱼久已，但无可奈何，因为没有更好的。

0x30 后记 ​

经历的越多，对很多事情越是无奈，因为作为普通人，很难去解决这些问题，要么忍，要么滚。

比如全平台泛滥的扩容盘，用扩容TF卡假冒SSD、大容量U盘，用二手机械硬盘假冒全新硬盘，淘宝、天猫、京东、PDD，每一个都有太多案例的，这些商品能进平台有一个算一个都有流程问题，但最后都是不懂的消费者买单，白花了钱是小事，丢了数据才麻烦。淘宝上的假SSD扩容盘，好友凌御曾经为此付出了巨大的努力和代价，然而成效维持了才多久又卷土重来？

再比如淘宝上翻新芯片、假芯片，低价引流，问题太多太多了，但你又有什么办法？你能如何？你改变不了什么，除了自己。

所以，看多了，就看开了，这个社会就是病态的，笑贫不笑娼，所以我现在也养成了偶尔刷刷暖心小视频的习惯，这个社会还是有很多美好的，很多人依旧善良，他们给这个社会带来了非常多的温暖和感动，让我们不至于对这个世界绝望。

我们改变不了别人，我们能做的，就是坚守自己的信念，Google不作恶的信念崩了，我们不能崩。

愿正义的人越来越多，愿世间越来越美好~~
